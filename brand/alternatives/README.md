# アイコンの別案

採用したのは A（`#545a92` の藍のタイルに象牙色の図柄、`../icon.png`）。次の 2 つは候補として残しているだけで、サイトでもアプリでも使っていない。

| ファイル | 案 |
| --- | --- |
| `icon-b-ivory-tile.png` | B: 象牙色のタイルに `#545a92` の図柄 |
| `icon-c-black-tile.png` | C: 黒いタイルに象牙色の図柄 |

どちらも 1024×1024 で、タイルの大きさと余白は A と同じ（1024 中 824px）。切り替えるときは `scripts/normalize-icons.py` のタイルと図柄の色を変えて `npm run icons` を実行する。
